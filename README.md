#Titanic EDA Project

#Objective
Exploratory Data Analysis on the Titanic dataset to find patterns in passenger survival.

#Key Findings
- Overall survival rate: 38.38%
- Women survived 74% vs Men only 19%
- 1st class passengers survived most (63%)
- 3rd class had the lowest survival (24%)
- Cabin column had 687 missing values

#Tools Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Jupyter Notebook

#Dataset
Titanic Dataset from Kaggle (891 rows, 12 columns)
